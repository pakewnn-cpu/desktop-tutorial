# 01 · 环境准备

搭 AI 环境之前，先把「地基」打好。这三样东西，后面每一步都用得到。

## 1. 打开「终端」

macOS 自带终端。按 `Command + 空格` 搜索 `终端`，回车打开。
所有命令都在这个黑框框里输入。

## 2. 安装 Homebrew（macOS 的「应用商店」命令行版）

后面装 Ollama、各种工具都靠它。只装一次：

```bash
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"
```

装完按提示把 brew 加进 PATH（终端会直接告诉你命令，复制回车即可）。
验证：`brew --version` 能打印版本号就成功了。

## 3. 安装 git（管理代码的工具）

```bash
xcode-select --install      # 第一次会弹窗，点「安装」
git --version               # 验证
```

## 4. 配置 git 身份（让提交带上你的名字）

```bash
git config --global user.name  "pakewnn-cpu"
git config --global user.email "your-email@example.com"   # 换成你的邮箱
```

> 这一步很关键：GitHub 的绿格子（贡献图）认的是「谁提交的」，
> 不配身份，提交就归属不到你头上。

## 5. 网络代理（国内访问 GitHub 更稳）

国内直连 GitHub 有时慢或失败。我用的代理软件叫「夜煞云」，
它在本机开了一个端口。让 git 走代理：

```bash
git config --global http.proxy  http://127.0.0.1:7892
git config --global https.proxy http://127.0.0.1:7892
```

> 端口 `7892` 是夜煞云默认的，以你软件里显示的为准。
> 哪天不用代理了，用 `git config --global --unset http.proxy` 关掉。

## 小结

- ✅ Homebrew 装好了
- ✅ git 装好并配了身份
- ✅ 代理配好了
