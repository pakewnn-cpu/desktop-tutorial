# 05 · 常见问题（FAQ）

## 环境

**Q：`setup.sh` 提示「本脚本目前只支持 macOS」？**
A：目前只支持 macOS。Linux / Windows 请先看对应平台的安装方式（Ollama 官网有）。

**Q：Homebrew 安装要输密码？**
A：正常，那是你的 Mac 登录密码（输入时屏幕不显示），回车即可。

**Q：国内直连 GitHub / 下载模型很慢或失败？**
A：开一个代理，让 git 走代理端口。本教程用的是「夜煞云」，默认端口 `7892`：

```bash
git config --global http.proxy  http://127.0.0.1:7892
git config --global https.proxy http://127.0.0.1:7892
```

> 端口以你软件里显示的为准；不用代理时用 `git config --global --unset http.proxy` 关掉。

## 本地模型（Ollama）

**Q：`ollama run` 卡住或内存不够？**
A：模型越大越吃内存。27B 级别的模型建议 16GB+ 内存；内存小的机器可换更小模型：
`MODEL=qwen2.5:7b bash scripts/setup.sh`。

**Q：本地模型接口地址是什么？**
A：默认 `http://localhost:11434`，把桌面 AI 助手的模型来源指向它即可。

## 桌面 AI 助手

**Q：桌面版连不上本地模型？**
A：确认 ① Ollama 已启动（`ollama serve`）；② 模型已拉取（`ollama list` 能看到）；③ 来源地址写的是 `http://localhost:11434`。
