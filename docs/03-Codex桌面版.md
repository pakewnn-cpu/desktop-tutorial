# 03 · 桌面 AI 助手 Codex

**Codex 桌面版**是一个能读写你电脑文件、帮你写代码/做事的 AI 助手。
把它接到上一步的本地模型，就得到一个「本地 + 离线」的桌面助手。

## 1. 安装

从官网下载 macOS 版，双击安装，登录你的账号。
（如果官网打不开，走 [01](01-环境准备.md) 里的代理。）

## 2. 接入本地模型

在 Codex 的设置里，把「模型 / 模型来源」指向本地 Ollama：

- 模型地址（Endpoint / Base URL）：`http://localhost:11434`
- 模型名称：`qwen-codex:27b`（和你 `ollama list` 里的一致）

> 具体菜单名称可能随版本变化，找「Model / Provider / 模型来源」这类入口即可。

## 3. 日常用法

- 把仓库文件夹交给它，让它读代码、改代码、跑命令。
- 复杂任务让它先「出计划」再动手，你审一遍再执行。
- 重要改动让它用分支（branch），别直接改主分支。

## 4. 配合本地模型的好处

- **隐私**：代码不上传云厂商。
- **离线**：断网也能用。
- **省钱**：本地跑不花 API 钱。

## 小结

- ✅ 桌面助手接上了本地模型
- ✅ 形成「本地模型 + 桌面助手」的闭环
