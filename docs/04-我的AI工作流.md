# 04 · 我的 AI 工作流

工具装好了，关键是**怎么用出节奏**。这是我的日常流程，供参考。

## 一天的节奏

1. **早上（5 分钟）**：打开 Codex 桌面版，把今天要做的任务说清楚。
2. **干活（随时）**：让 AI 先出计划 → 我审 → 它动手 → 我审结果。
3. **收尾（5 分钟）**：把今天的改动 `git commit` 一次，写清「今天做了什么」。

## 三条原则

- **先计划，后执行**：复杂任务让 AI 先给方案，别一上来就改。
- **小步提交**：每完成一小块就提交一次，提交信息写清楚。
  （这既是好习惯，也是 GitHub 绿格子的来源——见 [30 天计划](30天GitHub运营计划.md)）
- **本地优先**：能本地跑就别上云，隐私 + 省钱 + 离线。

## 工具分工

| 工具 | 干什么 |
| --- | --- |
| Ollama | 本地跑大模型，数据不出本机 |
| Codex 桌面版 | 读写文件、写代码、跑命令的助手 |
| git + GitHub | 管理代码、记录成长、对外展示 |
| GitHub Actions | 每次提交自动跑检查，省得手动 |

## 小结

环境搭好了，剩下就是**持续用、持续提交**。
具体怎么坚持 30 天，看 [30 天 GitHub 运营计划](30天GitHub运营计划.md)。
